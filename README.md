# GeoField Pro — Фаза 2 (Expo SDK 54)

## Запуск
Требуется Node.js 20 (nvm use 20). Затем:

    npm install
    npx expo start

Отсканируйте QR-код приложением Expo Go на Android.
Если разные сети: npx expo start --tunnel

## Что нового в Фазе 2
- 4 вкладки как в LandStar: Проект / Работа / Задачи / Настройки
- Активный проект (модель LandStar: вкладки работают с текущим проектом)
- Съёмка точек с УСРЕДНЕНИЕМ ЭПОХ (настраивается) и порогом точности
- Библиотека кодов объектов (цвета, свои коды) + выбор кода при съёмке
- Съёмка ЛИНИЙ и ПОЛИГОНОВ по вершинам с черновиком на холсте
- БД точек: поиск, редактирование, удаление
- Линии/полигоны: длина, площадь, периметр
- ВЫНОС ТОЧКИ (стейкаут): стрелка по компасу, дистанция, дельты С/В/H,
  вибросигнал при попадании в допуск 0.5 м
- COGO-калькуляторы: ПГЗ, ОГЗ, Площадь по каталогу, Углы ГМС, Осреднение
  (математика покрыта 24 юнит-тестами)
- Экспорт: CSV точек и GeoJSON всего проекта через системное меню

## Структура
    app/(tabs)/       4 вкладки
    app/survey.tsx    съёмка точек (усреднение)
    app/survey-feature.tsx  съёмка линий/полигонов
    app/points.tsx    БД точек
    app/stakeout.tsx  вынос точки
    app/features.tsx  список объектов
    app/codes.tsx     библиотека кодов
    app/export.tsx    экспорт CSV/GeoJSON
    app/cogo/         5 калькуляторов
    src/lib/cogo.ts   геодезическая математика (тесты: 24 passed)
    src/db/           SQLite: projects, points, features, codes, kv
